Blistering Production Analytics Platform (BPAP)
Data Analyst (Trainee) · JOSWE Pharmaceutical
Feb 2026 — Jun 2026

A production data and quality-improvement system built to replace manual Excel-based tracking across JOSWE's Blistering Department, rooms B1 and B3 through B7. Raw shift-level data now moves through a structured ETL pipeline into a Microsoft SQL Server database, surfaces through an interactive Power BI solution, and feeds a controlled, browser-based data-entry interface — delivered across four phases.

Phase 1 — Excel audit & silent error repair

Audited six source Excel workbooks, detected silent data issues, and prepared the source data for controlled processing before it reached the database.

Phase 2 — Data cleaning & ETL pipeline

Designed and documented an ETL pipeline covering extraction, cleaning, and schema validation, loading everything into SQL Server under ALCOA++ data integrity principles.

Phase 3 — Power BI dashboard construction

Authored 10+ DAX measures — Utilization Rate, Yield %, Delay Rate, Achieved Batch % and more — converting 20+ documented Excel formulas into equivalent DAX logic.

Phase 4 — Full-stack data-entry UI

Built a 5-page data-entry application covering the dashboard, session and batch information, activity & time log with auto-calculated fields, and delay entry in HTML/CSS/JS with RTL Arabic support, backed by a Node.js/Express REST API.

Projects

03
ForecastIQ — Demand Forecasting & Inventory Planning Dashboard
Independent project · Runs entirely in the browser

A retail analytics web app that turns uploaded Excel/CSV sales history into demand forecasts, stock-out risk alerts, and suggested reorders, with no data leaving the user's device.

  • Forecasting engine: damped additive Holt-Winters in vanilla JavaScript with automatic parameter tuning, seasonality detection, confidence intervals (80/95/99%), what-if scenarios (promotional surge, supply shock), and hold-out backtesting reported as WAPE and RMSE.
  • Inventory risk: days of cover, reorder points from configurable lead time and safety stock, suggested order quantities and purchase-order values, auto-approval limits, and critical/low/healthy classification.
  • Secure file ingestion: .xlsx, .xls, and .csv files up to 25 MB parsed in a Web Worker, with zip-bomb protection, guided column mapping, locale-aware number and date parsing, and reporting of skipped rows.
  • Dashboard: 6 responsive pages with KPI cards, custom SVG forecast charts, category and region filters, searchable product tables, alerts, and CSV export.
  • Privacy & reliability: IndexedDB storage, configurable auto-deletion, XSS-safe escaping, validation of stored data, a built-in demo dataset, and a downloadable Excel template.

My Tasks — Full-Stack To-Do Web App
Independent project · Node.js, Express, PostgreSQL

A fast, clean task manager with a vanilla JavaScript front end and a Node.js + Express + PostgreSQL REST API.

  • REST API: 5 endpoints (list, create, update, reorder, delete) backed by a PostgreSQL schema, with consistent JSON error responses and correct HTTP status codes (200, 201, 204, 400, 404, 413, 500).
  • Validation: server-side checks for title length, category and priority whitelists, and calendar-valid due dates, plus a 10 KB request body limit.
  • Security: parameterized SQL queries, whitelisted dynamic column names, XSS-safe rendering via textContent, and environment-based configuration with dotenv.
  • Features: categories and priorities, due-today/overdue indicators, live search with filters, drag-and-drop reordering persisted to the database, undo for deleted tasks, light/dark theme, and summary counters.
  • Documentation: setup guide, API reference, field rules, and example requests.
